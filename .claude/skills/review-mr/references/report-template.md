# Report Template

Template cho báo cáo tổng hợp kết quả review MR.

## File Location

```
.work/review-mr/REVIEW-YYYYMMDD--{mr-slug}.md
```

Trong đó `{mr-slug}` = `{platform}-{number}-{sanitized-title}`.

Ví dụ: `REVIEW-20260605--github-123-add-user-auth.md`

## Overall Verdict Logic

Tính overall verdict dựa trên severity cao nhất từ tất cả subagents:

```
Nếu có CRITICAL (security), URGENT (arch), hoặc BLOCKER (impact/ops) → URGENT
Nếu có BUG_FOUND (bugs), VIOLATION (conventions), hoặc HIGH_RISK (impact/ops) → NEEDS_ATTENTION
Còn lại → APPROVED
```

## Severity Color Coding (for terminal display)

| Severity | Color | Meaning |
|----------|-------|---------|
| URGENT / CRITICAL | 🔴 Red | Must fix before merge |
| BUG_FOUND / VIOLATION | 🟠 Orange | Should fix before merge |
| NEEDS_ATTENTION | 🟡 Yellow | Review recommended |
| POTENTIAL / WARNING | 🔵 Blue | Consider addressing |
| APPROVED / COMPLIANT | 🟢 Green | No concerns |
| NIT / SUGGESTION | ⚪ Grey | Optional improvement |
