# Workflow: Full Review Orchestration

Workflow chi tiết khi user chọn full review (`--full` hoặc menu "Full Review").

## Principle

Main agent (SKILL.md) điều phối, KHÔNG tự review. Tất cả analysis được delegate cho 6 subagents chạy song song.

## Step-by-Step Orchestration

### Step 1: Fetch MR Content

```bash
# GitHub
gh pr diff <number> --repo <owner/repo>
gh pr view <number> --repo <owner/repo> --json title,author,headRefName,baseRefName,additions,deletions,files,url,createdAt

# GitLab
glab mr diff <number> --repo <owner/repo>
glab mr view <number> --repo <owner/repo> --output json
```

### Step 2: Analyze Diff Structure

Trước khi dispatch, phân tích sơ bộ:
- Tổng số file thay đổi
- Phân loại: code, config, docs, test, dependency
- Có CLAUDE.md files trong repo không?
- Có ADR directory không?
- Có dependency files thay đổi không?

Thông tin này giúp subagents có context ban đầu.

### Step 3: Prepare Subagent Inputs

Mỗi subagent nhận input giống nhau:
```
MR Diff: {full unified diff}
MR Metadata:
  - Title: {title}
  - Author: {author}
  - Branch: {source} → {target}
  - Files: {file_count}
  - Additions: {+additions}
  - Deletions: {-deletions}
  - URL: {url}
Repo Path: {absolute path}
Platform: {github | gitlab}
```

### Step 4: Dispatch All 4 Subagents in Parallel

**CRITICAL**: Launch all subagents simultaneously, not sequentially.

```
Agent(review-mr-arch)        ─────┐
Agent(review-mr-security)    ─────┤
Agent(review-mr-bugs)        ─────┤
Agent(review-mr-conventions) ─────┼─ ALL AT ONCE
Agent(review-mr-impact)      ─────┤
Agent(review-mr-ops)         ─────┘
```

Use `run_in_background: true` cho từng agent để chúng chạy thực sự song song.

### Step 5: Wait for All Subagents

Đợi tất cả 6 subagents hoàn thành. Mỗi subagent trả về:
```json
{
  "verdict": "APPROVED | NEEDS_ATTENTION | URGENT/CRITICAL/BUG_FOUND/VIOLATION",
  "findings": [
    {
      "severity": "...",
      "category": "...",
      "description": "...",
      "recommendation": "...",
      "affected_files": ["..."]
    }
  ]
}
```

### Step 6: Merge and Deduplicate

**Merge logic**:
- Cùng một issue bị flag bởi nhiều subagents → merge thành 1 finding
- Ví dụ: "Missing input validation on /api/users" được flag bởi:
  - Security (A03 Injection — XSS risk)
  - Bugs (Edge case — null input crash)
  → Merge thành 1 finding với categories: [Security, Bugs]

**Deduplication criteria** (2 findings là trùng khi):
- Cùng file + cùng line range
- Cùng mô tả vấn đề (similarity check)

### Step 7: Compute Overall Verdict

```
if any(CRITICAL in security) or any(URGENT in arch) or any(BLOCKER in impact/ops):
    overall = "URGENT"
elif any(BUG_FOUND in bugs) or any(VIOLATION in conventions) or any(HIGH_RISK in impact/ops):
    overall = "NEEDS_ATTENTION"
else:
    overall = "APPROVED"
```

### Step 8: Generate Report

Dùng template từ `references/report-template.md`.

### Step 9: Save Report

```bash
# Tạo thư mục nếu chưa có
mkdir -p .work/review-mr

# Lưu report
# Path: .work/review-mr/REVIEW-YYYYMMDD--{platform}-{number}-{sanitized-title}.md
```

### Step 10: Offer to Post Comments

```yaml
question: "Post findings lên MR/PR?"
options:
  - label: "Post tất cả findings"
    description: "Mỗi finding sẽ được post thành 1 comment riêng trên MR/PR"
  - label: "Chỉ post CRITICAL + URGENT + BLOCKER"
    description: "Chỉ post findings có severity cao nhất (block merge)"
  - label: "Không post, chỉ lưu report"
```

Nếu user chọn post:
- Mỗi finding → 1 comment
- Dùng `gh pr comment` hoặc `glab mr note`
- Format: `**[{severity}] [{dimension}]** {description}\n\n**Recommendation**: {recommendation}\n\n**File**: \`{file}\`\n\n🤖 Generated by review-mr skill`

## Timing Considerations

- Full review với 6 subagents có thể mất 3-15 phút tùy kích thước MR
- Subagents chạy song song → wall clock ≈ thời gian subagent chậm nhất
- Thông báo cho user: "Đang chạy full review với 6 subagents, có thể mất vài phút..."

## Partial Failure Handling

Nếu 1+ subagents fail:
- Vẫn tổng hợp kết quả từ các subagents còn lại
- Ghi chú trong report: "⚠️ {dimension} review failed: {error}"
- Cho user lựa chọn retry subagent(s) bị fail
