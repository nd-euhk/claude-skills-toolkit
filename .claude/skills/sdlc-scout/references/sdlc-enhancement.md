# SDLC Enhancement

How to enhance `scout` skill output with SDLC-specific sections. The `scout` skill produces a markdown report with file listings and basic patterns. For SDLC consumption (review agents, explore pipeline), add these structured sections.

## When to Enhance

Always enhance when `mode=review` — review agents need structured data to decide which files to read. For `mode=explore`, the pipeline workflow handles enhancement internally.

## Enhancement Process

### Step 1: Read Scout Report

Read the report generated by `scout` skill from `.work/scouts/scout-YYYYMMDD-{topic}--{slug}.md`.

### Step 2: Extract + Enrich

Use an Explore agent to read the report and the actual source files to add:

#### Modules and Responsibilities

For each logical module found, add:
- **Name** — module identifier
- **Responsibility** — what it does (1 sentence)
- **Dependencies** — other modules it depends on
- **Public API** — key exported functions/classes

Agent prompt:
```
Read the scout report at {reportPath}. Then explore the source code of 
the top-N files (high relevance only) to identify logical modules.

For each module, determine:
1. Responsibility — what does this module do?
2. Dependencies — what other modules does it import/call?
3. Public API — what are the key exported symbols?

Add to report as a "## Modules và Trách Nhiệm" section.
```

#### Entry Points Table

Scan for all entry points and add a table:
```
| Entry Point | Type | Path | Description |
|-------------|------|------|-------------|
| main()      | CLI  | src/index.ts | Application bootstrap |
```

Types: `HTTP Handler`, `CLI Command`, `Event Handler`, `Worker`, `Cron Job`, `gRPC`, `GraphQL`, `Middleware`, `Startup Hook`.

#### Dependency Mapping

Read config files to build external dependency table:
```
| Package | Version | Purpose |
|---------|---------|---------|
| express | ^4.18.0 | HTTP framework |
```

For internal dependencies, build cross-module dependency graph:
```
| Module | Depends On | Relationship |
|--------|-----------|--------------|
| auth   | database  | Reads user records |
| auth   | cache     | Stores sessions |
```

#### Architectural Patterns

Identify patterns with concrete evidence:
```
- **Repository Pattern** — src/db/user-repo.ts:15 implements data access layer
- **Middleware Chain** — src/middleware/ chain in src/app.ts:42-56
```

### Step 3: Write Enhanced Report

Overwrite the scout report with enhanced version. Keep all original sections, add SDLC sections.

## Token Budget

- Enhancement agent: 1 Explore agent, schema output
- Timeout: 3 minutes
- If scout report has >20 high-relevance files → sample top 10
