# Report Format Reference

Template đầy đủ cho scout report. Dùng làm reference khi cần tạo report mới hoặc verify format.

## File Location

`.work/scouts/scout-YYYYMMDD-{topic}--{slug}.md`

## Report Template

```markdown
# Scout Report: {name}

**Ngày:** {timestamp}
**Loại:** {projectType}
**Đường dẫn:** {paths}
**Focus:** {focus || 'toàn bộ'}

## Tổng quan
{2-3 sentence summary}

## Tóm tắt
- Tổng số file: N (H high, M medium, L low)
- Patterns: N
- Technologies: N
- Modules: N
- Entry Points: N

## Các File Liên Quan
### Mức Độ Cao (N)
- `path/to/file.ts` — reason (exports: keyExports)

### Mức Độ Trung Bình (N)
- `path/to/file.ts` — reason

### Mức Độ Thấp (N)
- `path/to/file.ts` — reason

## Công Nghệ Sử Dụng
| Category | Technology | Version | Purpose |
|----------|-----------|---------|---------|

## Cấu Trúc Thư Mục
```
src/
├── auth/       - description
├── api/        - description
└── models/     - description
```

## Modules và Trách Nhiệm
- **module-name** — responsibility (depends on: deps)
  - Public API: exported functions/classes

## Entry Points
| Entry Point | Type | Path | Description |
|-------------|------|------|-------------|

## Dependencies
### Internal
| Module | Depends On | Relationship |
|--------|-----------|--------------|

### External
| Package | Version | Purpose |
|---------|---------|---------|

## Architectural Patterns
- **Pattern Name** — evidence (file:line)

## Câu Hỏi Chưa Giải Quyết
- gaps or areas needing deeper investigation

---

*Report generated by sdlc-scout*
```

## Các trường bắt buộc

| Trường | Mô tả |
|--------|-------|
| `name` | Tên sub-project |
| `outputPath` | Đường dẫn file report |
| `filesFound` | Tổng số file tìm thấy |
| `highRelevance` | File có relevance cao |
| `patternsObserved` | Số architectural pattern |
| `technologiesDetected` | Số công nghệ phát hiện |
| `modulesFound` | Số module đã map |
| `entryPointsFound` | Số entry point |
